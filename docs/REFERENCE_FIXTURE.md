# Landmark reference fixture

The positive fixture is the scikit-image 0.23.2 astronaut image, a NASA public-domain photograph. Its download and exact SHA-256 are in ci/fetch-test-image.sh. The synthetic negative fixture is a solid RGB 30/75/105 image generated by the test runner.

The desktop baseline used MediaPipe Python 0.10.21 on CPU, IMAGE mode, one face, without blendshapes or transformation matrices, with the model verified by ci/fetch-model.sh. The solid image returned no faces. The astronaut image returned 478 points. ANTARES compares every native x, y and z coordinate to the desktop baseline, allowing a maximum absolute difference of 0.005 normalized units. This is a regression fixture for this image and configuration. Historical report parity still needs matching source files.

To regenerate the reference with the pinned Python package installed, use `mp.tasks.vision.FaceLandmarker.create_from_options`, set `mp.tasks.BaseOptions(model_asset_path=…)`, prepare an `mp.Image` from the fixture in RGB, and export each point's x, y and z in model order.
